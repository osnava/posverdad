# Mapa de la posverdad

Guía de estudio interactiva sobre la posverdad, construida a partir de la conferencia «La posverdad» de Darío Sztajnszrajber (Facultad Libre de Rosario, 2018) y de fuentes verificadas.

**Sitio publicado:** https://osnava.github.io/posverdad/

## Contenido

- Mapa de 28 estaciones organizadas en líneas de argumento, con recorrido guiado y pregunta de control por estación.
- Bloques «Hecho / interpretación», «El 1 %» y «Las costuras».
- Seis casos para practicar, con análisis y estudios citados.
- Siete casos reales con enlaces a la noticia, el documento oficial o el estudio para comprobarlos.
- Errores de la conferencia, tabla comparativa de las dos salidas y lecturas esenciales.

## Estructura

- `index.html`: la página completa. Es un solo archivo; solo carga las fuentes tipográficas desde Google Fonts.
- `.nojekyll`: indica a GitHub Pages que publique los archivos tal cual.

## Actualización

El archivo de trabajo vive en la carpeta de estudio (`02_estudio/mapa-interactivo.html`). Para actualizar el sitio:

1. Copiar ese archivo como `index.html`.
2. Hacer commit y push en la rama `main`.

GitHub Pages publica el cambio en uno o dos minutos.
